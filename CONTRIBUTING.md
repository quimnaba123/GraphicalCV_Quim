# Contributing to Graphical CV

Thank you for your interest in contributing! This document provides guidelines for contributing to the Graphical CV project.

## 🚀 Getting Started

1. Fork the repository
2. Create a feature branch (`git checkout -b feature/amazing-feature`)
3. Make your changes
4. Commit your changes (`git commit -m 'Add some amazing feature'`)
5. Push to the branch (`git push origin feature/amazing-feature`)
6. Open a Pull Request

## 📋 Development Guidelines

### Code Style

- Use meaningful variable and function names
- Follow existing code patterns
- Add comments for complex logic
- Use ESLint to check code quality

### Testing

Before submitting a PR:
- Test your changes locally
- Ensure no console errors in the browser
- Check responsive design on mobile devices

### Documentation

- Update README.md for major changes
- Add inline comments for new code
- Update CHANGELOG.md for releases

## 🎨 Feature Requests

Feel free to submit feature requests! When adding new features:

1. Update the relevant data objects in `src/main.js`
2. Add new visualizations or animations
3. Test performance with new features
4. Update documentation

## 🐛 Bug Reports

If you find a bug:

1. Check if it's already reported in issues
2. Provide clear steps to reproduce
3. Include relevant screenshots if possible
4. Mention your browser and version

## 📝 Commit Messages

Follow conventional commit messages:

```
feat: add new project section
fix: resolve navigation scrolling issue
docs: update installation instructions
style: improve color contrast
perf: optimize Three.js rendering
```

## 🤝 Code Review

- Be respectful and constructive in reviews
- Acknowledge and appreciate contributions
- Suggest improvements rather than just criticizing
- Provide context for your feedback

## 💬 Getting Help

Have questions? Feel free to:

- Open an issue for bugs or questions
- Start a discussion for feature requests
- Check existing documentation

Thank you for making this project better! 🎉
